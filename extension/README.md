# Paperplane 0.5.0

A personal layout and sidebar for Slack in Chrome, by Thin-K-ayn.

Open Slack at https://app.slack.com/client/ after installation and refresh existing tabs. Use the Telegram style / Original Slack switch to change layouts. Your profile is detected automatically when Slack exposes its member ID; Set my messages remains a fallback.

Choose Containers above the sidebar. Create containers and one level of subcontainers; use + to add chats and the three-dot menu for icons, colors, pins, renaming, moving, or removal. Unread badges count chats, not messages. Muted chats do not contribute to badges and sort below unmuted chats within each pin group.

Preferences stay local to this browser profile and workspace. No server, telemetry, or automatic sharing of your organization. Do not uninstall an existing unpacked copy before arranging migration: a Web Store installation has separate storage. Running both copies at once is unsupported.
