## Short description

A calmer Slack with message bubbles, nested sidebar containers, custom icons and colors, and a switch to the original layout.

## Detailed description

Make Slack on the web feel more like a familiar chat app.

Paperplane gives Slack Telegram-inspired message bubbles and a personal sidebar you can organize around your work. Switch back to the original Slack layout whenever you want.

• Message bubbles with your own messages aligned right. Paperplane detects your account from the rendered profile when available, with a manual fallback.
• Containers and one level of subcontainers to organize channels and chats.
• Custom container icons and text colors, automatic heading sizes, and local pins.
• Unread-chat badges and clear unread indicators. Muted conversations do not contribute to the badges and appear below unmuted chats within each pin group.
• An in-page toggle and extension popup to restore the original Slack appearance.

GET STARTED
Install Paperplane, open Slack in Chrome, and refresh existing Slack tabs. Choose Containers above the sidebar, then + New. Use + to add chats and the three-dot menu to customize or organize them.

LOCAL AND PERSONAL
Paperplane runs only on Slack client pages. It reads rendered profile and conversation metadata to provide these features and saves preferences in Chrome local extension storage. It has no backend, telemetry, advertising, or remote executable code. It does not store message bodies or send Slack data to the developer. Your container organization does not sync to teammates or other devices.

BETA LIMITATIONS
For Slack's web app in Chrome only. Slack's markup can change, and some surfaces keep their original appearance. Unread badges count conversations, not individual messages, based on the native sidebar state available to the extension. Switch to Original Slack if a layout issue occurs.
